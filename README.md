# 🚑 SARATHI
### AI-Powered Emergency Response & Smart Dispatch System

> **Every second matters. SARATHI ensures the right help reaches the right place at the right time.**

---

## 🌟 Overview

SARATHI is an AI-driven emergency response platform that automates emergency call handling, prioritization, and resource dispatch.

Instead of relying on manual coordination, SARATHI listens, understands, analyzes, prioritizes, and dispatches emergency services within seconds using intelligent AI agents.

🧠 AI-powered Voice Assistant

📞 Real-time Emergency Call Processing

🗺️ Interactive Dashboard

## 🤖 AI Agent Pipeline

### 🎧 Intake Agent
- Understands emergency conversations
- Extracts important information
- Detects emergency type

### 🚨 Triage Agent
- Calculates severity
- Assigns priority score
- Estimates urgency

### 🚑 Dispatch Agent
- Finds nearest available ambulance
- Calculates ETA
- Dispatches resources automatically

### 📊 Monitoring Agent
- Tracks every decision
- Maintains audit logs
- Supports explainable AI

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/sriaswanth/SARATHI.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the backend

```bash
uvicorn app.main:app --reload
```

Run the frontend

```bash
npm install
npm run dev
```
